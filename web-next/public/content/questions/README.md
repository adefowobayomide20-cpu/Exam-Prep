# Question bank content

Static JSON exports of the exam question banks that live in the Flutter app
at `lib/features/exam/quiz/question_bank/*.dart`.

## Structure

```
<examCategory>/<subject-slug>.json
```

- `examCategory` is one of `waec`, `neco`, `jamb`, `post-jamb`.
- `subject-slug` is the subject name lowercased with spaces/punctuation
  turned into hyphens (e.g. "Christian Religious Studies" ->
  `christian-religious-studies`).

Each file has the shape:

```json
{
  "subject": "History",
  "examCategory": "waec",
  "questions": [
    {
      "subject": "History",
      "text": "...",
      "options": ["...", "...", "...", "..."],
      "correctIndex": 0,
      "explanation": "..."
    }
  ]
}
```

`questions[].explanation` may be `null`.

## Coverage

Only (subject, examCategory) pairs that have a dedicated hardcoded bank in
the Flutter app are present here. Pairs that fall back to AI-generated /
placeholder content in the app (the `(_, _) => null` case in
`question_bank_registry.dart`) are intentionally absent — there's no static
content to export for them.

## Provenance / regenerating

This content was generated from the Dart question banks via
`tool/export_question_banks.dart` (run from the Flutter project root with
`dart run tool/export_question_banks.dart`). That script mirrors the
`(subject, examCategory) -> builder function` switch table in
`lib/features/exam/quiz/question_bank/question_bank_registry.dart`.

**If the Flutter question banks are ever updated (new subjects, edited
questions, etc.), re-run that script to keep this folder in sync.** If the
registry's switch table changes (new subject/category mapping added or
removed), update `tool/export_question_banks.dart` to match first.

## `post-utme-schools/` (school-first Post-UTME flow)

A separate folder, `post-utme-schools/<school-slug>/<subject-slug>.json`,
powers the school-first Post-UTME flow at `/post-utme/[school]/[subject]`
(pick a university before a subject, matching the Flutter app — see
`lib/features/exam/post_jamb_schools.dart`). Same file shape as above.

- `post-utme-schools/<school-slug>/` — real, curated per-school content for
  the 8 schools that have it in the Flutter app: `unilag`, `unilorin`, `ui`,
  `oau`, `uniben`, `unn`, `futa`, `lautech`.
- `post-utme-schools/_common/` — the shared Post-UTME practice pool
  (English Language / Mathematics / General Knowledge), reused as
  general-practice fallback content (clearly labeled as such in the UI, not
  implied to be official past questions) for every other school, which has
  no dedicated bank yet.
- Fallback schools also reuse the existing generic `post-jamb/` bank
  (Mathematics / Further Mathematics / Biology) — see
  `src/lib/post-utme-content.ts`.

Generated by `tool/export_post_utme_schools.dart` — re-run it the same way
if the underlying Dart Post-UTME banks change.
